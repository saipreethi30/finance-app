# Smart Finance Tracker

## Technologies Used

| Layer | Technology |
|-------|------------|
| Language | Core Java |
| Build | `javac` |
| Collections | `ArrayList`, `HashMap`|
| Database | JDBC |

## Features

- **Income & Expense CRUD** — add, list, update, delete transactions
- **Category-wise Reports** — totals grouped by category
- **Monthly Balance Report** — income, expense, net per month
- **Search & Filter** — by date range and transaction type
- **UI** — Console menu, Swing desktop, JavaFX with charts
- **Charts** — pie chart (expenses), bar chart (monthly income vs expense)
- **Export** — CSV and text reports to `exports/` folder
- **Authentication** — login and register (multi-user)
- **Overspending Notifications** — budget warnings at 80% and 100%+

## Requirements

- **Java 17 or higher** (Java 21 works)
